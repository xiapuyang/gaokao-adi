# gaokao-adi · 中国高考志愿专业路径测评

> 一个 [Claude Code](https://docs.claude.com/en/docs/claude-code) Skill：先按分数告诉你"能报哪些专业"，再给候选专业打一个"这条路你走得通吗"的综合分。
> 基于风灵之声「专业路径 ADI（Action Domain Index）」模型的工程化复刻。

两个功能，可单独用也可串行用：

- **① 按成绩推荐专业** — 给省份 + 高考成绩 + 选考科目 + 喜欢/不喜欢科目，输出可报专业的四档排序（`strong / consider / not_recommended / ineligible`）。
- **② ADI 综合测评** — 对 1–3 个候选专业做个性化打分（`1–625`），覆盖 paths / reach / correct / recover 四维度，生成 Markdown 报告 + HTML 单页可视化（含雷达图）。

---

## ⚠️ 免责声明

**仅供志愿填报参考，不构成任何录取保证或专业建议。** 高考志愿是高风险决策，请以教育部、各省考试院、目标院校官方招生章程为准。

ADI 的算法是从风灵之声公开案例**反推**的工程实现（作者私有算法不公开），目标是**分档结论一致**（低/中/较难/高难），**不是数字精确对齐**——请把分数当作专业间的**横向比较**，不要把 `312 vs 287` 当成精确差距。

## 安装

本工具以 Claude Code Skill 形式使用。把仓库放到 `~/.claude/skills/` 下即可被自动发现：

```bash
git clone https://github.com/xiapuyang/gaokao-adi.git ~/.claude/skills/gaokao-adi
```

> 需要 **Python ≥ 3.10**（代码使用 PEP 604 联合类型注解）。**运行时零第三方依赖**，只用标准库，无需 `pip install`。

装好后重启 Claude Code，确认 skill 已加载即可。

## 使用

直接用自然语言对 Claude 说话即可，skill 会自动触发并引导后续流程。

**① 按成绩推荐专业：**

```
我是广东考生，物理类，语文 115 数学 138 外语 130 物理 90 化学 85 生物 82，
选科物化生，喜欢数学不喜欢语文，能报哪些专业？
```

**② ADI 综合测评（已有候选专业）：**

```
帮我看看 经济学 / 英语 / 法学 这三个专业，哪条路更走得通？
```

Claude 会就读一份 14 题素质问卷，然后给出测评。两者也可串行：先推荐 → 你挑 3 个 → 进 ADI 测评。

## 输出样例

**① 按成绩推荐专业**（节选 Top 6）：

```
strong   应用数学              fit=0.92   数理逻辑/数据分析/工程应用
strong   数据科学 / 人工智能      fit=0.91   数理逻辑/技术/创造性
strong   数学                 fit=0.91   数理逻辑/抽象思维/基础科学
strong   物理                 fit=0.91   实验科学/数理逻辑/基础科学
strong   统计学                fit=0.91   数理逻辑/数据分析/实证科学
strong   计算机类 / 软件工程      fit=0.91   数理逻辑/技术/创造性
```

**② ADI 综合测评**（Markdown 报告节选）：

```
## 三专业评分

| 排名 | 专业 | 总分 | 分档 | 主要瓶颈 |
|---|---|---|---|---|
| 1 | 经济学 | 511.25 | 🟢 低难 | 损失可控性 |
| 2 | 英语/外语 | 272.40 | 🟡 中等 | 损失可控性 |
| 3 | 法学   |  29.66 | 🔴 高难 | 纠偏能力 |

### 1. 经济学 — 511.25 🟢 低难

| 维度 | 基础 | 个人系数 | 调整后 | 条形 |
|---|---|---|---|---|
| 路径数量   | 4 | ×1.22 | 4.87 | ██████████ |
| 成功可达性 | 3 | ×1.87 | 5.00 | ██████████ |
| 纠偏能力   | 4 | ×1.76 | 5.00 | ██████████ |
| 损失可控性 | 4 | ×1.05 | 4.20 | ████████░░ |

🚀 主要拉抬：Q14=A 把「路径数量」+25%
⚠️ 瓶颈维度：损失可控性（最低维度锁住总分上限）
```

ADI 还会同时生成一张 **HTML 单页**（4 维度雷达图 + 逐专业卡片），可直接在浏览器打开。
